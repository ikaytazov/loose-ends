# Loose Ends landing page package

- `CLAUDE-CODE-PROMPT.md`: paste into Claude Code.
- `reference/loose-ends-landing.html`: the built page. Open it in a browser; it's the source of truth for layout and copy.
- `reference/design-reference-landing.png`: Telly's chosen design.
- `assets/`: the text-free images and 3 transparent thread dividers (WebP for the site, PNG originals). Copy them to `public/landing/`.
- `screenshots/`: desktop and mobile renders.

Put this folder at `docs/handoff/landing/` in the repo.
- `app-threads/`: the quieter thread rules and mockups for the app's main pages.
